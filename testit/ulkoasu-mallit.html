Tiivis valitsin (tyyli.css v3)

Paljon tilaa vievät valinnat napin taakse. Napissa näkyy valinta, jotta tietää, mitä lista näyttää. Muu kuin oletus → nappi värillinen.

Lomake-ikkuna (tyyli.css v3)

Tietokoneella keskellä ruutua, puhelimella koko ruudulle ja napit alalaidassa. Kokeile kapealla ikkunalla.

Uuden sivun muistilista (opittua R0–R6)
  • Pohja: tyyli.css?v=3 + teema.js?v=1 <head>issa, <body class="kpt-sivu">, yläpalkki kpt-yla kuten tällä sivulla, valikko nav.js?v=6. Uusi sivu valikkoon yhdellä rivillä nav.js:n listaan.
  • Värit vain muuttujina (--kpt-...), ei kiinteitä värejä. Tarkista sivu molemmissa ulkoasuissa.
  • Puhelin: kentät 16 px (iPhone ei zoomaa), napit vähintään 44 px, verstaalla käytettävät isommiksi. Lomakkeet koko ruudulle.
  • Kuvat paperille: piirretään ruudun väreillä, sivu muuntaa KPT_PELLIT.paperiVarit-funktiolla vaalealle paperille (kpt-piirros paperi). Tulosteet mustavalkoisina (tyokortti.js).
  • Tulosteet: body.kpt-sivu muuttaa fonttikokoa ja riviväliä. Tulosteeseen @media print { body.kpt-sivu { font-size: 16px; line-height: normal } }, ja vertaa tuloste vanhaan.
  • Linkkinappi (<a class="kpt-nappi">) saa linkin korostusvärin; jos se pitää olla tekstin värinen, aseta väri sivulla.
  • Vanhan sivun siirto: kytke vanhat värinimet uusiin (:root, html[data-teema] { --vanha: var(--kpt-...) }), rakenne ja skripti ennallaan, ja vertaa tallennukset vanhaan versioon.
